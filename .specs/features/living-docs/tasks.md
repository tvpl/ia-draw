### T1: Add `markdownUrl` to the 3 docgen route responses

**What**: `POST /diagrams/:id/specs:generate`, `GET /diagrams/:id/specs`, and `POST
/diagrams/:id/specs/:version:regenerate-section` each attach a signed-read `markdownUrl` (TTL
3600s, same constant pattern as `export/routes.ts`'s `EXPORT_URL_TTL_SECONDS`) to every
`spec_documents` row in their response body — additive field only, no schema/behavior change to
request handling.
**Where**: `apps/server/src/modules/docgen/routes.ts`
**Depends on**: None
**Reuses**: `storage.getSignedUrl` (`apps/server/src/modules/storage/signedUrl.ts`, already the

`apps/server/src/modules/export/routes.ts` (`EXPORT_URL_TTL_SECONDS`).
**Requirement**: LDC-12 (content-fetch precondition — no AC is directly "the field exists", but
every content-reading AC in P1's second story depends on it existing)
**Tests**: `apps/server/src/modules/docgen/docgen.int.spec.ts`,
`apps/server/src/modules/docgen/regenerateSection.int.spec.ts` (integration)
**Gate**: `make lint && make typecheck && make test-unit && make test-integration`

**Tools**:
- MCP: NONE
- Skill: NONE

**Done when**:
- [x] A local `SPEC_URL_TTL_SECONDS = 3600` constant (or equivalent) is defined in `routes.ts`,
      matching `export/routes.ts`'s value and rationale comment style.
- [x] All 3 handlers attach `markdownUrl` to the `spec` object(s) they return, computed via
      `storage.getSignedUrl(EXPORT_BUCKET, spec.markdownKey, SPEC_URL_TTL_SECONDS)`; the list route
      computes one per row (`Promise.all`, not a serial loop).
- [x] `docgen.int.spec.ts` and `regenerateSection.int.spec.ts` gain at least one assertion per route
      confirming `markdownUrl` is present and matches the fake storage's
      `https://fake-storage.test/<bucket>/<key>` shape from `createFakeStorage()` — every existing
      assertion in both files keeps passing unmodified.
- [x] Gate: `make lint && make typecheck && make test-unit && make test-integration` green (server
